# Phases and gates

The plan's build-plan diagram wasn't readable in the exported file, so phases are reconstructed from the plan text.
Build one phase at a time; don't start the next until its gate is met.

## Phase 0 — Foundation ✅ built
Local server (127.0.0.1, random port, session token, Host check, CSP) · SQLite WAL + versioned migrations + daily/pre-migration
backups · sync-ready records (UUID, device id, updated_at, deleted) · Sand and Paper themes as `themes/<name>/theme.json`
with an automated WCAG AA contrast test · bundled fonts (Atkinson Hyperlegible, Literata, OpenDyslexic) · error log, no telemetry.

## Phase 1 — Minimum useful reader ✅ built
- **Import:** PDF (pypdfium2, Apache/BSD — swapped in for AGPL PyMuPDF: font-size headings, table rows and footnotes set aside, keyword sections, two-column order, running headers removed, captions,
  equations, references, rotated margin stamps ignored), arXiv (HTML version, PDF fallback), web articles (trafilatura),
  Markdown/text. Failed imports fall back to plain text and keep the original. Fix-the-structure view. Clean view.
- **Reading engine:** sentence pacer, word pacer, focus-word mode, density score (word rarity + length + numbers + symbols +
  acronyms, plus a learned personal slow-down per sentence), read aloud with word sync (offline voices preferred),
  energy modes (low blurs text ahead), focus view, background skipping, reading comfort saved per document type,
  section map, click any word to restart, keyboard first, lazy section rendering.
- **Understanding:** claim-to-question builder, question templates by section type that learn from your questions,
  Q+n paragraph tagging, three-pass plan, prediction prompts with compare-at-end, guess gate, definition finder,
  acronym expander, personal glossary, figure/table/equation/citation peeks, back-jump, explain-it box, confusion-first.
- **Notes:** 5 typed highlights (keys 1–5), margin notes, "in my words" answers, auto summary sheet, idea inbox,
  Markdown + JSON export.
- **Focus:** one-tap resume, 5-second session setup, time box, end-of-session next step, distraction guard,
  speed ramp, reading queue with "why" and deadlines.

### Phase 1 gate — check these yourself
- [ ] Import 5 of your real files (put copies in `tests/fixtures/real/` and run `uv run pytest`) — open question #1.
- [ ] Read 3 real papers past the intro with the pacer; key-sentence coverage ≥ 70%.
- [ ] Opening the app → reading in under 30 seconds.
- [ ] Pick an offline voice in Settings and confirm read-aloud works with Wi-Fi off.

## Phase 2 — Memory (partly built early)
Built because they fell out of Phase 1 data: FSRS cards from guesses, definition highlights, answered questions and
evidence blanks; daily capped review; glossary + concept pages.
**Still to do:** end-of-document quiz (a day after finishing), exam mode (timed quiz by course/tag), course/tag field.

## Phase 3 — Stamina and ambience (partly built)
Built: stamina stats, low-day streak, weekly review, sand-jar progress.
**Still to do:** animated themes (Rain, Forest, Garden, Cloud, Galaxy, Night sky, Pixel art) as one-canvas scene modules ≤30 fps,
time-of-day palettes per theme, optional CC0 sounds, battery-saver mode.

## Phase 4 — Optional AI plug-in (later, off by default)
Local OpenAI-compatible server only (Ollama / llama.cpp). Perplexity density, drafted questions, one-line term help,
answer grading — always after your own attempt. Plus anything parked for later.
